# Summarize chat for next agent

When this command is run:

1. **Review the current conversation** and identify what was actually done (files created/edited, decisions made, patterns established).
2. **Write a short context summary** for the next agent in a single, easily copiable markdown block.
3. **Keep it efficient:** bullet points, no repetition, only what the next agent needs to continue (project context, paths, key conventions or changes).
4. **Output the summary** in a fenced markdown block so the user can copy it into the next chat or into a file.

Do not include this instruction block in the summary. Produce only the summary content in the copyable block.
